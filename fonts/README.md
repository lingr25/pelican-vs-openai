# Fusion Pixel

The UI and canvas text use the locally bundled simplified Chinese, proportional 12px Fusion Pixel font (2026.09.01 release).

Source: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.01

The release asset `fusion-pixel-font-12px-proportional-otf.woff2-v2026.09.01.zip` supplies this unmodified font. Its filename is shortened locally. `OFL.txt` and upstream component notices under `LICENSES/` are preserved from that archive. The portable build embeds the font and its license text, so no font CDN or network access is required.
